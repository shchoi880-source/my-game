# ZERO SIGNAL — 총알 피하기

탄막의 틈을 읽고, 총알에 스쳐 `FLOW`를 쌓고, 위상 대시로 4분 생존 프로토콜을 돌파하는 Canvas 2D 게임입니다.

플레이 주소: https://shchoi880-source.github.io/my-game/zero-signal/

## 게임 특징

- 90초 입문 / 150초 표준 / 4분 최종 임무
- 실제 캐릭터보다 작은 5px 피격점, 3칸 보호막, 2회 충전 대시
- 총알 스치기 → 콤보 배율 → 5초 오버드라이브의 위험 보상 구조
- 5단계 시드 기반 탄막과 사전 경고, 기능색·형태를 함께 쓴 가독성
- 키보드와 멀티 포인터 터치 조작, 일시정지, 효과 줄이기
- 절차적 WebAudio 사운드, 로컬 최고 기록, 오프라인 PWA
- 120Hz 고정 스텝 엔진 및 Node 자동 검증

## 조작

- 이동: `WASD` / 방향키 / 화면 드래그
- 집중: `Shift` / FOCUS 버튼 — 느리게 이동하고 피격·그레이즈 범위를 표시
- 위상 대시: `Space` / DASH 버튼 — 짧은 무적과 탄환 파괴
- 일시정지: `Esc` 또는 `P`
- 재시작: `R`

## 난이도 · 점수 · 등급

- **NORMAL / HARD**: 같은 피격점(5px)과 스치기 범위. HARD는 탄막 밀도 x1.5(임무별 보정), 탄속 +12%,
  사전 경고 0.65→0.45초(레이저 0.8→0.6초), 대시 충전 2.8→3.6초, 보호막 수리는 보스 시작 때만.
- **겹치는 타임라인**: 기본층(전 구간 저속 링) + 구간 주력 패턴 + 3구간부터 압박층. 구간 안에서 밀도가
  0.7x→1.3x로 오르고, 다음 구간 직전 2초는 0.4x로 숨 돌릴 틈을 줍니다. 조준 부채꼴은 항상 홀수 발,
  벽의 틈은 항상 플레이어에게서 60px 이상 떨어져 있어 가만히 서 있으면 모든 구간에서 맞습니다.
- **보스(코어 개방)**: 코어가 HP를 갖고 스펠 카드(공명 꽃잎 · 격자 붕괴 · 영점 수렴)를 차례로 씁니다.
  스치기 1, 대시로 지운 탄 3만큼 피해를 주며, 시간 안에 카드를 깨면 보너스와(무피격 시) 보호막 +1.
  마지막 `제로 시그널`까지 HP를 모두 깎으면 코어 격파 보너스.
- **점수**: 생존 10/초, 스치기 60 x 콤보 배율(오버드라이브 중 x2), 위상 대시 80. 콤보 타이머 2.5초가 끝나면
  콤보는 절반으로 줄고(피격 시 0), 무피격 구간 보너스와 남은 보호막 보너스가 붙습니다.
- **등급**: D(실패) / C / B / A(피격 1회 이하) / S(무피격) / SS(무피격 + 대시 0회). 점수 기준은 임무·모드별로
  `js/patterns.js`의 `grades`에 있습니다.

밸런스 검사 (`tools/balance.js`, 임무·모드별 10개 시드):

- 제자리 파일럿은 모든 구간에서 피격
- 사람형 파일럿(약 180ms 반응, 조준 오차 ±10°, 대시 4초에 1회)이 NORMAL을 8/10 이상, HARD를 3~7/10 클리어
- 숙련 파일럿(매 2스텝 판단, 스치기 추구)이 각 임무 HARD를 1회 이상 무피격 클리어

```powershell
node tools/balance.js            # 전체 게이트 (약 3~5분)
node tools/balance.js --quick    # 시드 4개, 게이트 없이 표만
node tools/balance.js --mission zero --mode hard --pilot human
```

## 로컬 실행 및 검증

정적 파일이라 별도 빌드가 없습니다. 서비스 워커까지 확인하려면 프로젝트 루트에서 정적 서버를 실행하세요.

```powershell
python -m http.server 8080
```

엔진·패턴 검사:

```powershell
node tools/verify.js
```

## 구조

| 파일 | 역할 |
|---|---|
| `js/core.js` | 공통 유틸, 저장, 접근성, 파티클 |
| `js/patterns.js` | 임무 데이터와 탄막 패턴 |
| `js/engine.js` | 120Hz 이동·판정·점수 엔진 |
| `js/render.js` | 배경, 탄막, HUD, VFX |
| `js/audio.js` | 절차적 음악과 합성 효과음 |
| `js/screens.js` | 타이틀, 임무 선택, 플레이, 결과 |
| `tools/verify.js` | 결정성·판정·성능 상한·API 자동 검사 |
| `tools/balance.js` | 파일럿 시뮬레이션으로 난이도 게이트 검사 |

GitHub Pages의 `main / (root)` 브랜치 배포와 하위 경로에서 바로 동작하도록 모든 경로는 상대 경로입니다.
