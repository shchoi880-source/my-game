# 곱셈 디펜스

게이트(+, ×, −, ÷)를 골라 통과하며 병력을 늘리고, 몰려오는 몬스터와 보스를 방어선 앞에서 막는 디펜스 게임.
PC와 휴대폰 브라우저에서 동작하며, 한 번 접속해 설치하면 인터넷 없이도 실행됩니다 (PWA).

플레이: https://shchoi880-source.github.io/my-game/

## 게임 요소
- **몬스터 4종**: 슬라임, 박쥐(빠르고 지그재그), 골렘(느리고 단단함), 분열체(죽으면 둘로 갈라짐)
- **보스 3종** (40초마다 등장, 스테이지마다 교대)
  - 킹 슬라임: 슬라임을 소환
  - 화염 악마: 불덩이 발사 (피하거나 쏴서 터뜨리기)
  - 바위 거인: 빨간 구역에 바위 낙하 (구역 밖으로 피하기)
- **무기 상자**: 쏴서 부수면 연사 / 화력 / 확산 / 관통 강화
- **게이트 사격**: 게이트를 쏘면 숫자가 커지고, 마이너스 게이트는 플러스로 뒤집힘
- **코인 업그레이드**: 시작 병력 / 기본 화력 / 코인 보너스 (기기에 저장)

## 조작
- PC: 마우스 이동 또는 ← → (A / D) 키, P·Esc 일시정지
- 휴대폰: 화면을 좌우로 드래그

## 오프라인 설치
- 안드로이드(Chrome): 메뉴 → "앱 설치" / "홈 화면에 추가"
- 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
- PC(Chrome/Edge): 주소창 오른쪽 설치 아이콘

## 업데이트 시 주의
파일을 수정해서 올릴 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 기기에도 새 버전이 반영됩니다.
