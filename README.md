# 네온 대시 (NEON DASH)

자동으로 달리는 네온 큐브. **탭 = 점프, 공중에서 한 번 더 탭 = 2단 점프.**
가시·톱날·구멍에 닿으면 즉사, 0.4초 만에 재시작. 장애물은 음악 박자에 맞춰 배치된 극악 난이도 러너.
폰·PC 브라우저에서 동작하고, 홈 화면에 설치하면 인터넷 없이 실행됩니다(PWA, 가로 화면).

플레이: https://shchoi880-source.github.io/my-game/

## 콘텐츠
- 레벨 5개 (쉬움 → 극악): 첫 박자 / 빛의 계단 / 톱니 정원 / 거꾸로 내리는 비 / 임계점
- 레벨마다 다른 절차적 음악(120~160 BPM), 비밀 코인 3개, 최고 기록 %, 시도 횟수
- 연습 모드(자동 체크포인트), 기록 카드 이미지 공유
- 모든 레벨은 자동 풀이기(`tools/verify.js`)로 완주 가능함을 검증

## 조작
- 폰: 화면 탭 / PC: 스페이스, ↑, W, 클릭 · 일시정지 Esc, P

## 개발 구조 (팀 분업, `docs/SPEC.md`)
| 파일 | 역할 |
|---|---|
| `js/core.js` | 캔버스·유틸·글로우 스프라이트·저장 |
| `js/audio.js` | 효과음·절차적 음악·박자 시계 |
| `js/levels.js` | 레벨 데이터(박자 정렬) |
| `js/engine.js` | 물리·판정(240Hz 고정 스텝) |
| `js/render.js` | 월드 그리기·이펙트 |
| `js/screens.js` | 타이틀·레벨 선택·플레이·클리어 화면 |
| `js/main.js` | 로딩·입력·루프 |
| `tools/verify.js` | 레벨 완주 가능성 검증 (`node tools/verify.js`) |

## 업데이트 시 주의
파일을 수정해서 올릴 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 기기에도 새 버전이 반영됩니다.
