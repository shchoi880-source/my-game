# 곱셈 디펜스

게이트(+, ×, −, ÷)를 골라 통과하며 병력을 늘리고, 몰려오는 몬스터와 보스를 방어선 앞에서 막는 디펜스 게임.
PC와 휴대폰 브라우저에서 동작하며, 한 번 접속해 설치하면 인터넷 없이도 실행됩니다 (PWA).

플레이: https://shchoi880-source.github.io/my-game/

## 콘텐츠
- **월드 4개 × 5스테이지 = 20스테이지**: 초록 초원 / 모래 사막 / 얼음 설원 / 용암 요새
  - 스테이지마다 별 3개 도전: 클리어 · 방어선 돌파 3회 이하 · 보스 30초 안에 처치
- **보스 4종** (등장 컷신, 처치 슬로모션): 킹 말랑(소환), 플레임 혼(불덩이), 프로스트 골렘(바위 낙하), 다크 오버로드(전부)
- **몬스터 4종**: 말랑이, 날쌘돌이(빠르고 지그재그), 뿔통이(단단함), 세눈이(분열)
- **영웅 8명** (고유 스킬): 일제 사격, 수류탄, 응급 처치, 방어막, 화염 폭풍, 헤드샷, 시간 정지, 메가 레이저
- **무기 4종**: 권총, 기관단총, 샷건, 저격총 (레벨업)
- **강화**: 시작 병력 / 기본 화력 / 스킬 충전 / 코인 보너스
- **출석 보상(7일)**, **일일 미션 3개**, **업적 8종**
- 효과음, 월드별 배경음악(절차적 생성), 보스 테마

## 조작
- PC: 마우스 이동 또는 ← → (A / D), 스킬 Space / E, 일시정지 P · Esc
- 휴대폰: 화면을 좌우로 드래그, 오른쪽 아래 버튼으로 스킬

## 오프라인 설치
- 안드로이드(Chrome): 메뉴 → "앱 설치" / "홈 화면에 추가"
- 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
- PC(Chrome/Edge): 주소창 오른쪽 설치 아이콘

## 구조
- `js/core.js` 캔버스·유틸·저장·에셋 로더 / `js/data.js` 게임 데이터 / `js/audio.js` 효과음·BGM
- `js/battle.js` 전투 / `js/ui.js` 메뉴·팝업 / `js/main.js` 장면·입력·루프
- `assets/` 아틀라스(main, monsters, fx), 효과음(sfx), 폰트

## 업데이트 시 주의
파일을 수정해서 올릴 때는 `sw.js`의 `VERSION` 값을 올려야 설치된 기기에도 새 버전이 반영됩니다.
